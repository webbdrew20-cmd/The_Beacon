How Messages Works

Messages travel by radio, not the internet — they hop from one Beacon radio to the next until they arrive. No cell service, no WiFi from the outside world, nothing else needed. If the power and internet are out, this still works.

Send to everyone

Leave the "To" box empty, type your message, press send. Every Beacon radio in range hears it — like speaking on a shared walkie-talkie channel.

Send to one person

Every Beacon radio has an ID — 8 letters and numbers, like a3f91c02. Put that in the "To" box and only that person's Beacon shows the message.

  • Easiest way: when someone messages you, tap their name above their message — the "To" box fills in by itself. Reply and go.
  • The page remembers the last person you wrote to.
  • Worth doing now, not during an emergency: keep a short paper list of your family's Beacon IDs taped near the device. Paper doesn't run out of battery.

What the bubbles mean

  • Bubbles on the right — things you sent.
  • Bubbles on the left — things you received. The small name above shows who sent it.
  • Dashed bubbles in the center — notices from the radio itself (for example, if a message couldn't be transmitted).

The radio badge

Top-right of the Messages page: radio online means the radio is powered and talking to Beacon. radio offline means it isn't — check that the radio box has power before trusting any message to go out.

Test it anytime

Type /echo hello and send it. Within a few seconds a reply comes back from your own radio. That one test proves the whole path works — page, Beacon, radio, and back. Good habit: run it once in a while on a calm day, so you're not discovering a problem on a bad one.

Honest limits — please read once

  • No delivery receipts. Sending is like calling out on a radio — you don't get confirmation it was heard. For anything important, ask for a reply, and resend if none comes.
  • Not private. Messages are broadcast over open radio. Anyone with similar equipment could listen. Treat every message like a postcard: fine for "we're safe, meet at the church," wrong for passwords or anything secret.
  • Range depends on terrain. Across a neighborhood is realistic; through a mountain is not. More Beacon radios between two points = more hops = more reach.
For the person who maintains this device

Finding a radio's ID: it prints on the USB serial monitor when the radio board boots (Node ID: xxxxxxxx). Write it on the device with a label maker or tape.

What /echo actually tests: the message travels web page → Beacon hub → UART → radio board → its stored inbox → back up the same chain. Everything except the antenna itself. Testing true over-the-air delivery requires a second radio node.

If the badge says offline: the radio board isn't heartbeating. Check its power and the UART wiring to the hub, in that order.

If sends produce a dashed "TX failed" notice: the radio chip rejected the transmission — usually antenna or SPI wiring. The code number in the notice narrows it down.
